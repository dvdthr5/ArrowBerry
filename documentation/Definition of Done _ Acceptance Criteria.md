ArrowBerry Definition of Done: 

Task:   
	A task is not defined as done until: 

* The feature has been properly coded and works as intended.  
* The relevant documentation has been updated  
* Comments have been added to each new function marking description and return type  
* Style guidelines have been followed  
* Unit tests have been created and passed  
* You have locally tested and tried to break the new feature in every way you can think of, and have fixed any bugs that have appeared

User Story:  
	A user story is not defined as done until:

* All tasks are completed in their entirety (according to task definition of done)  
* Integration test(s) has been created and passed 

Acceptance Criteria: 

* Every piece of code must adhere to the style guide as defined in the typescript style guide  
* Every new function/ piece of code has been documented according to documentation/comment standards  
* Feature must work as intended  
* New code must pass all old unit and integration tests  
* New unit tests and integration tests have been created to test the new feature
